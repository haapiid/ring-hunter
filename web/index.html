Wallets thatmove together.

Early buyers are linked by a shared funding source, direct transfers, ties to the deployer, and closely timed buys. Exchanges, bridges, and hot wallets are excluded to avoid false positives.

  • STRONG_CORRELATIONseveral strong indicators at once — often includes the deployer
  • POSSIBLE_CLUSTERfunding indicators worth checking
  • OBSERVED_LINKone observed connection
  • UNVERIFIEDtiming coincidence only

Every cluster comes with tx-hash evidence and alternative explanations. On-chain correlation is not proof of shared ownership.

A score youcan audit.

Six components with fixed weights. Missing data is never treated as safe — the component is excluded and coverage drops.

AI writes.The engine counts.

Gemini or Groq only drafts the summary. Every address, score, and percentage the AI writes is checked against the engine's data — if anything doesn't match, the summary is rejected and the local analysis is used. The app runs fully even without an API key.

# ~/.ring-hunter/.env  — fill in one of them (optional)
AI_PROVIDER=groq
GROQ_API_KEY=…your key…
GROQ_MODEL=…a model name from your account…

# strongly recommended: ETH funding sources between wallets
BLOCK_EXPLORER_API_KEY=…free at dev.blockscout.com…

API keys are never printed and never sent to the AI.

Launch on Pons.Scan before you buy.

Tokens launched on the Robinhood side of the launchpad use Pons v2 — the same factory 0x7eD5…EC7e that RING-HUNTER reads. So you can check any Pons token before you buy it.

  1. Find a token on the launchpadSwitch the launchpad to the Robinhood network to see Pons tokens.
  2. Copy its addressThe 0x… address on the token's page.
  3. Scan itPaste the address after scan.

Different roles: RING-HUNTER only reads. The launchpad signs transactions through your wallet (launch, buy, sell, claim) — review every confirmation in your wallet. Solana tokens (base58 addresses) can't be scanned by RING-HUNTER.

“RPC connection failed: fetch failed”

Check your internet, then run ring-hunter check. The public RPC is sometimes busy — try again shortly, or set a private RPC in ROBINHOOD_CHAIN_RPC. Some internet providers block the RPC domain through their DNS — and they intercept plain DNS too, so only changing the DNS numbers to 1.1.1.1 often isn't enough. Turn on encrypted DNS instead. Windows 11: Settings → Network & internet → your connection → DNS server assignment → Edit → Manual → 1.1.1.1 / 1.0.0.1 with DNS over HTTPS: On. macOS/Linux/phones: install Cloudflare's 1.1.1.1 app or use a VPN. A private RPC (Alchemy, Chainstack) on another domain also works.

“ring-hunter” is not recognized

Close and reopen the terminal after installing. If it still fails, check that npm's global folder is on your PATH: npm prefix -g shows where it is.

ETH funding source shows NONE

Native ETH transfers aren't recorded in logs. Set BLOCK_EXPLORER_API_KEY (free) for a complete funding graph; without it, confidence is capped at MEDIUM.

Menu doesn't appear / “requires a terminal (TTY)”

Run ring-hunter from a regular terminal, not with redirected output. For automation, use ring-hunter scan <address> --json.

AI summary isn't used

Set AI_PROVIDER, the API key, and the model name in ~/.ring-hunter/.env. If the quota runs out or the answer fails validation, the local analysis is used automatically.
